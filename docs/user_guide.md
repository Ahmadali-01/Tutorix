# Tutorix — User Guide

## Login
URL: http://localhost:3000
Email: admin@tutorix.com
Password: admin123

## AI Tutor
1. Select a course from the dropdown
2. Type your question
3. Click Send
4. View answer + source citations

## Questions
1. Choose course, topic, difficulty, count, type
2. Click Generate
3. View MCQs with correct answers and explanations

## Curriculum
1. Enter subject, grade level, number of weeks
2. Click Generate Curriculum
3. Wait ~20 seconds for 4 agents to complete

## Agent Tools
Try: "What is 42 * 17?", "What time is it?", "Find questions about machine learning", "Stats for student a6f1f8de-c4c4-42e3-9a2e-e34c40aa7556"

## Analytics
Select a course, view total events, submissions, event breakdown
